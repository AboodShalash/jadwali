# جدولي 4.12

منصة دراسية عربية متكاملة: جدول أسبوعي، مهام بلغة طبيعية، اختبارات مع خطط مراجعة ذكية، مؤقت تركيز بأصوات محيطية، عالم العلوم حسب المنهاج الأردني بمراحله وحقوله (دروس، أسئلة على نمط الوزارة، بطاقات مراجعة متباعدة، اختبارات، مختبر تفاعلي)، إحصائيات وإنجازات، العلامات والمعدل الموزون مع حاسبة «كم أحتاج؟»، دفتر ملاحظات يحوّل «سؤال :: جواب» إلى بطاقات، تقويم شهري، وتذكيرات قبل الحصص، خطة يوم ذكية، مهام متكررة، وتحليل أفضل أوقات التركيز، ومزامنة عبر حساب.

## التشغيل
```
pip install fastapi uvicorn
python server/server.py   # http://localhost:8000
```

### المساعد الذكي وماسح الواجب (اختياري)
يعملان عبر الخادم بمفتاح Claude API، فلا يصل المفتاح للمتصفح:
```
export ANTHROPIC_API_KEY=sk-ant-...        # يفعّل /api/ai/ask و /api/ai/scan
export JADWALI_MODEL=claude-haiku-4-5-20251001   # اختياري
```
بدون المفتاح يبقى المساعد يجيب من قواعده المحلية، ويرجع الماسح لقراءة نصية محلية (Tesseract، تحتاج إنترنت أول مرة).

### الأصدقاء
صفحة `#/friends` تحتاج حساباً مسجّلاً؛ تُخزَّن أرقام مجمّعة فقط (تركيز الأسبوع، السلسلة، النقاط) وتُعرض للأصدقاء المقبولين.
الواجهة في `public/` (بدون بناء). قاعدة البيانات SQLite في `server/jadwali4.db`.
